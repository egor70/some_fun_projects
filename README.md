# 🚀 Sales Analytics Dashboard

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue?logo=python&logoColor=white)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.28%2B-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io/)
[![Plotly](https://img.shields.io/badge/Plotly-5.18%2B-3F4F75?logo=plotly&logoColor=white)](https://plotly.com/)
[![Pandas](https://img.shields.io/badge/Pandas-2.0%2B-150458?logo=pandas&logoColor=white)](https://pandas.pydata.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Интерактивный дашборд для анализа продаж, построенный на **Python** с использованием **Streamlit** и **Plotly**. Позволяет исследовать динамику выручки, категории продуктов, географию продаж и ключевые метрики в реальном времени.



---

## ✨ Основные возможности

- 📊 **Ключевые KPI** — общая выручка, количество заказов, средний чек, продано единиц
- 📈 **Динамика продаж** — интерактивный линейный график по месяцам
- 🏆 **Топ-5 клиентов** — кто приносит больше всего денег
- 🥧 **Категории продуктов** — круговая диаграмма с долями
- 🌍 **География** — топ-10 стран по выручке
- 🔍 **Фильтры** — по дате и категории продукта
- 📋 **Детальная таблица** — последние транзакции

# 🧬 Conway's Game of Life

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue?logo=python&logoColor=white)](https://www.python.org/)
[![NumPy](https://img.shields.io/badge/NumPy-1.24%2B-013243?logo=numpy&logoColor=white)](https://numpy.org/)
[![Matplotlib](https://img.shields.io/badge/Matplotlib-3.7%2B-11557c?logo=python&logoColor=white)](https://matplotlib.org/)
[![SciPy](https://img.shields.io/badge/SciPy-1.10%2B-8CAAE6?logo=scipy&logoColor=white)](https://scipy.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Визуализация классической игры «Жизнь» Джона Конвея с использованием **NumPy** для вычислений и **Matplotlib** для анимации. Симуляция клеточного автомата на поле 100×100 с настраиваемыми параметрами.

![Game of Life Demo](https://raw.githubusercontent.com/your-username/your-repo/main/screenshots/game_of_life.gif)

---

## ✨ Особенности

- 🧮 **Поле 100×100** — достаточно большое для наблюдения сложных паттернов
- 🎲 **Случайная инициализация** — 30% клеток изначально живые
- ⚡ **Быстрые вычисления** — использование свертки (`convolve2d`) для подсчета соседей
- 🎨 **Визуализация** — ч/б анимация с обновлением каждые 50 мс
- 🔄 **Циклические границы** — поле замкнуто в тор (wrap-around)
- 📊 **Информативный заголовок** — отображает номер текущего поколения
